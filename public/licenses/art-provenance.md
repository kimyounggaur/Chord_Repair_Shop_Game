# 제작 출처와 사용 범위

2026-10-19 · 화음 수리점 · 이미지 제작 패키지

- 배경 1개, 악기 3종의 2상태 6개, 손님 4명의 2표정 8개는 이번 요청을 위해 OpenAI 기본 이미지 생성 도구로 제작한 원본 이미지다. 외부 사진·상업 게임 이미지·기존 게임 캐릭터·로고는 입력하거나 재사용하지 않았다.
- 수리 후 상태 및 감사 표정은 해당 원본을 참조한 이미지 편집으로 제작했다. 원본과 수정본 모두 보존한다. 생성 도구가 반환한 PNG 크기는 배경 1448×1086, 나머지 1254×1254이다. 요청한 목표 크기와 실제 출력 크기를 혼동하지 않는다.
- `source/generation-prompts.json`에 모든 프롬프트와 참조 관계를 기록했다. 도구의 내부 이미지 모델 버전은 노출되지 않아 별도 확정하지 않는다. 이 패키지의 추론 모델 설정과 이미지 생성 모델은 별개다.
- 역할 토큰 15개와 제어 아이콘 5개는 이번 패키지에서 직접 작성한 독립 SVG다. 폰트, 외부 라이브러리, 외부 이미지, 스크립트를 포함하지 않는다. SVG 원본은 편집 가능하다.
- 후처리는 ImageMagick의 크기 조정·투명 여백 추가·WebP 압축·검수용 배치뿐이다. 그림을 코드로 대체하거나 생성된 일러스트라고 가장한 도형은 없다. Pillow는 치수·알파·해시 검사에만 사용한다.
- 사용자가 요청한 화음 수리점 프로젝트의 통합·수정·배포를 위한 전달물이다. OpenAI 서비스에 적용되는 계약과 관련 법률에 따른다. 독점성·저작권 성립·타인의 유사 권리 부재에 대한 법적 보증이나 제3자 라이선스 취득을 의미하지 않는다. 출시 전 최종 권리·상표 확인은 별도다.
- 실제 제작 파일·프롬프트·검수 사실을 기록했으며, 게임에 실제 사용하거나 공개 배포했다고 표시하지 않는다. 자산 장부의 `used_in_game`은 모두 false다.
- 래스터 원본은 평면 PNG다. 가상의 PSD 레이어나 원래 없던 벡터 원본을 제공한다고 주장하지 않는다. 배경·소품·손님·토큰은 별도 파일로 합성 가능하다.
- 미리보기의 제목·라벨은 검수를 위한 실제 HTML 텍스트다. 게임용 WebP/SVG 파일에는 음이름·주문번호·한국어 라벨·정답이 내장되어 있지 않다.

외부 아트 파일의 재배포 의무: 없음. 외부 폰트는 런타임에 포함하지 않는다. 미리보기는 시스템 글꼴을 사용한다.
