# S12 독립 전이 평가 준비안과 A/B 문항

작성일: 2026-10-19 UTC. 상태: **문항·절차 준비만, 평가 미실시(NOT RUN)**. 참가자 응답·점수·효과 수치는 없다. A/B는 난이도 구조를 맞춘 제안이며 평행성·타당도·신뢰도를 실증 검증한 검사가 아니다. 시행은 S11 이후 후보 검토와 연구 실행 승인·동의가 갖춰진 뒤 판단한다.

기준: [설계서](../design.md) 12장·22장, [프롬프트팩](../promptpack.md) S12. A형에 원문 12.4의 필수 예시를 보존하고 B형은 같은 목표를 다른 근음/음역/문항 순서로 제시하는 연구용 후보다. CR01–CR08 정답·학습 순서·합주 해금·앱의 MVP 범위를 바꾸지 않는다.

## 세 결과와 독립성

| 결과 | 자료 | 해석 |
|---|---|---|
| 플레이 성취 | CR01–CR08 최종 수리, 도움 사용 가능 | 과제 완료 여부 |
| 앱 개념 확인 | 앱 질문 첫 응답 + repair/reflection 도움 + 답 노출 | 해당 앱 맥락에서의 개념 확인; 이미 본 해설 뒤 응답은 연습 |
| 독립 전이 | 별도 미노출 문항, 다른 타일/배치/근음/악기 | 해당 새로운 조건으로의 적용; 항목별 탐색 결과 |

앱의 같은 질문을 다시 묻거나 선택적인 “다른 모양으로 확인하기”에서 이미 연습한 문항을 외부 전이로 집계하지 않는다. 평가용 자료는 `transfer/A/*`, `transfer/B/*` 식별자를 쓰며 앱 학습 저장/보상과 연결하지 않는다. 화면낭독기·큰 버튼·확대·무음·reduced motion은 이론 힌트가 아니다. 정답에 해당하는 거리·역할·음이름을 제공하면 노출이다.

독립 응답 자격은 문항을 처음 봄, 첫 응답 전 정답/직접 유도 없음, 조건과 도구 기록, 첫 응답을 보존함의 네 가지로 확인한다. 증거 불명확은 `unknown`이며 독립으로 추정하지 않는다. A/B 배정 전에 원문/문항/앱 밖 같은 문제를 본 경험도 가능한 범위에서 확인한다.

## 일정과 순서 제안

- 사용성 파일럿은 입문자 6–8명이라는 가정일 뿐 교육효과 연구 표본 수가 아니다. 교육효과를 판단하려면 연구 담당자가 사전 능력·목표 효과·비교 조건·분석과 별도 표본 수를 정한다.
- 사전→게임 경험→사후. 참가자 코드를 기준으로 AB 또는 BA에 균형 배정하고 배정 방법/실제 순서를 기록한다. 기초경험/숙련도 집단은 구분한다. 현재 어떤 참가자도 배정하지 않았다.
- A/B 내부 문항 순서는 고정 정답 위치가 반복되지 않도록 사전에 정해 기록한다. 도구 조작 숙지 연습은 음악 정답을 포함하지 않는 중립 자료로 한다.
- 사전/사후 전체 평가가 끝나기 전 즉시 정답 피드백을 하지 않는다. 안전·접근성 지원은 가능하되 답을 알려주었으면 기록한다. 평가 종료 후 해설한다.
- 가능하면 7–14일 지연 평가를 제안한다. 동의 없는 연락·자동 일정·알림은 만들지 않는다. A/B를 이미 모두 사용했다면 지연 평가에 같은 문항을 쓰는 것은 반복측정이며 새 문항 전이가 아니다. 제3의 미노출 형태는 추가 제작·검수 후 사용한다. 해설 후 재사용한 문항은 특히 노출 상태를 남긴다.
- 같은 시간 같은 개념을 배우는 비게임 비교 조건/무작위 배정은 향후 효과 연구의 설계 후보다. 현재 적용하거나 연구 성과로 주장하지 않는다. 게임군 단독 전후 변화로 게임의 인과효과를 단정하지 않는다.

## 공통 제시 조건

음 타일은 한 물리 음고당 하나, 문자 음이름과 필요 시 고정도 보조를 제공한다. 목표 음을 색·위치·크기로 강조하지 않는다. 답은 슬롯의 화면 순서가 아니라 정해진 음고 다중집합으로 확인한다. 건반의 이명동음 보조 이름 때문에 오답을 만들지 않으며 철자 선택 자체를 별도 평가하지 않는다. 음이름 철자 설명을 따로 관찰하면 수리/구성 점수와 구분한다.

구성 문항은 지정 근음·음역을 문장에 포함해 옥타브 조건을 숨기지 않는다. 정답보다 충분히 넓은 타일 목록을 제공하되 두 형식의 선택 수/입력 방식/반음표 유무를 맞추고 기록한다. 반음표는 거리 계산 보조 조건이며 제공한 검사와 미제공 검사를 섞어 비교하지 않는다. 점수는 다음 표의 항목별 관찰 기준이며 음악 능력 종합점수나 검증된 절단점이 아니다.

## A/B 문항과 정답

| 목표/ID | A형 제안 | B형 제안 | 정답·관찰 기준 |
|---|---|---|---|
| 역할 `ROLE` | C4 E4 G4에서 근음과 3음 지목 | F4 A4 C5에서 근음과 3음 지목 | A: C4/E4, B: F4/A4. 근음·3음 각각 정답1/오답0. 배치만으로 판단했는지 설명은 별도 |
| 간격 `INTERVAL` | 장3화음, 단3화음 순서로 근음→3음 반음 수 질문 | 단3화음, 장3화음 순서로 질문 | major4/minor3. 각 관계 정답1/오답0. 문자 3도를 세 건반으로 이해했는지 관찰 |
| 새 배치 `LAYOUT` | E4 G4 C5가 C의 음 모음인가? 이유는? | A4 C5 F5가 F의 음 모음인가? 이유는? | 둘 다 예. A C/E/G, B F/A/C 구성음 보존 설명. 판단1/설명1을 별도 기록. “제1전위” 용어 불필요; 기본 목표 통과율에서 제외 |
| 새 근음 단 구성 `MINOR-BUILD` | A3를 근음으로 A3~E4 범위의 단3화음 세 음 구성 | D4를 근음으로 D4~A4 범위의 단3화음 세 음 구성 | A A3 C4 E4=`[57,60,64]`; B D4 F4 A4=`[62,65,69]`. 구성 정답1/0, 3·7반음 이유 여부 별도 |
| 수리 불필요 `NO-REPAIR` | A3 C4 E4는 A단3화음 주문에 맞는가? 고쳐야 하는가? | D4 F4 A4는 D단3화음 주문에 맞는가? 고쳐야 하는가? | 그대로 맞음/수리 불필요. 유지 판단1/0; 3·7 관계 설명 여부 별도. 아래 노출 통제 규칙 적용 |
| 새 근음 장 구성 `MAJOR-BUILD` | D4를 근음으로 D4~A4 범위의 장3화음 구성 | A3를 근음으로 A3~E4 범위의 장3화음 구성 | A D4 F#4 A4=`[62,66,69]`; B A3 C#4 E4=`[57,61,64]`. 구성 정답1/0, 4·7반음 이유 여부 별도 |
| 청각 비교 `HEAR` | 같은 C근음/reference로 C·Cm 두 화음 | 같은 F근음/reference로 F·Fm 두 화음 | 더 높은 3음은 major쪽. 재생 A/B 위치를 균형화하여 실제 위치와 선택 기록. 정답1/0; 출력 미확인/무음은 미실시 |
| 다른 도구 `INSTRUMENT` | 다른 가상 악기 또는 허용된 실제 악기에서 C장→C단 | 같은 종류의 다른 도구에서 F장→F단 | A E→Eb, B A→Ab: 3음만 반음 낮춤. 올바른 음 선택1/0, 실제 조작/운지/도구 숙련도 별도 |

`MINOR-BUILD`와 `NO-REPAIR`는 같은 정답을 공유한다. 두 문항을 연속 제시한 뒤 모두 미노출 독립 표본으로 더하지 않는다. 독립 분석에서는 사전에 둘 중 하나를 배정하고 반대 문항은 NOT ADMINISTERED로 둔다. 전체 문항을 관찰할 필요가 있으면 구성 응답을 먼저 확보한 뒤 수리 불필요 문항을 탐색적으로 제시하고 `relatedItemExposed=true`로 표시해 독립 분석에서 분리한다. A/B 사전·사후에도 같은 하위 목표가 비교되도록 동일한 분기 규칙을 유지한다.

## 정답 검산 기준

| 형태 | 표기 | MIDI | 근음 기준 간격 |
|---|---|---|---|
| A단 | A3 C4 E4 | 57,60,64 | 0,3,7 |
| D장 | D4 F#4 A4 | 62,66,69 | 0,4,7 |
| D단(B제안) | D4 F4 A4 | 62,65,69 | 0,3,7 |
| A장(B제안) | A3 C#4 E4 | 57,61,64 | 0,4,7 |
| C 새 배치 | E4 G4 C5 | 64,67,72 | 음고류 4,7,0 = C/E/G |
| F 새 배치(B제안) | A4 C5 F5 | 69,72,77 | 음고류 9,0,5 = F/A/C |

B형의 D단/A장과 F의 새 배치는 문서 작성자의 평행 후보이며 원문 주문의 새 정답이 아니다. A/B는 익숙한 역할, 같은 장·단 관계, 흰건반 단화음, 샤프 하나를 포함하는 장화음으로 구조를 맞췄지만 근음 선행지식·음역·음색 차이로 난이도가 달라질 수 있다. 담당자가 문구·타일 수·반음표·출력 조건을 검수하고 파일럿 결과 없이 “동등 난이도”로 단정하지 않는다.

## 채점과 결측 처리

- 각 판단/구성/관계의 첫 응답을 보존하고 수정 응답은 별도 칸에 적는다. 최종 성공으로 최초 오답을 덮지 않는다.
- 잘못된 음을 골랐는지, 다른 옥타브를 썼는지, 조작 오탭인지, 설명은 맞지만 조작을 못했는지 분리한다. 지정 음역을 벗어난 구성은 exact 구성 기준과 음고류 관계 이해를 별도 기록한다.
- 정답 및 오답은 실제로 문항을 제시하고 유효 응답을 받았을 때만 부여한다. skip/휴식·종료/출력 불확실/도구 실패/미배정/증거 unknown은 결측 사유와 함께 기록하며 0점으로 임의 환산하지 않는다.
- 도움이나 정답 노출 뒤 정답이면 정답 여부는 기록하되 `independentEligible=false`로 둔다. 접근성 편의 자체는 이 플래그를 바꾸지 않는다.
- 채점자에게 가능한 경우 사전/사후 시점을 가리고 두 명의 독립 채점을 비교한다. 실제 두 번째 검토가 없으면 단일 채점이라고 명시한다. 현재 채점은 수행하지 않았다.
- 항목별 수/분모/노출·결측·경험 조건을 제시한다. 배치 인식과 다른 악기 과제는 탐색적 전이이며 기본 개념 통과율과 합치지 않는다. 사전 고득점의 천장 효과와 문항 반복 효과를 보고한다.

## 오개념을 구분하는 탐색 질문

| 오개념 후보 | 관련 문항/관찰 | 중립 질문과 해석 제한 |
|---|---|---|
| C장에는 E라는 음만 외움 | F역할/새 근음 구성 | “근음이 바뀌었을 때 어떤 관계를 확인했나요?”; 실패만으로 암기를 확정하지 않음 |
| 단화음은 검은건반 하나 | A단/D단 구성·수리불필요 | “이 음 모음이 조건에 맞는다고 판단한 이유는 무엇인가요?” |
| 항상 한 음을 고쳐야 함 | NO-REPAIR | 첫 수정 여부와 판단 이유를 별도 기록 |
| 가운데 음=3음 | LAYOUT/CR07·08 | 타일 위치와 역할의 근거 확인. 전위 용어를 요구하지 않음 |
| 근음=항상 최저음 | 새 배치 | 낮은 음이 바뀌어도 구성음/화음 이름 보존 여부 탐색 |
| 장=좋음·단=나쁨 | HEAR와 설명 | 느낌은 선택적 경험, 정오·보상과 연결하지 않음 |
| C화음=C장조 | 역할/설명 | 한 화음과 조성 개념을 혼동하는 발언을 기록하되 조성 시험 추가 없음 |

2026-10-19 PowerShell에서 앱 코드를 사용하지 않는 표기 파서와 `12*(octave+1)+naturalPc+accidental` 계산으로 위 여섯 표기/MIDI 행을 검산했다(exit 0). 네 기본 위치 화음의 간격은 각각 `[0,3,7]`, `[0,4,7]`, `[0,3,7]`, `[0,4,7]`이었다. 새 배치의 첫 음 기준 거리는 `[0,3,8]`이며 이를 근음 기준 간격으로 오인하지 않는다. C/F 음고류 보존으로 판단한다.

현재 검증 범위는 문서 정답과 설계 정합성의 검산이다. 사람에게 제시하거나 교육효과를 측정하지 않았다. 별도 음악교육 담당자의 독립 검수·A/B 파일럿·실제 청각/악기 조건 확인은 미실시다.
