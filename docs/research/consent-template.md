# S12 참여 설명 및 데이터 계획 초안

작성일: 2026-10-19 UTC. 상태: **준비 초안, 실제 동의 취득·모집·연락·기록 수집 없음**. 미확정 칸을 채우고 담당자가 대상·운영 조건을 검토하기 전 참여자에게 확정 안내문으로 전달하지 않는다. 이 초안이 기관 심의나 특정 지역의 법적 적합성을 확인한 것은 아니다.

기준: [설계서](../design.md) 2장, 12장, 19.1장과 [프롬프트팩](../promptpack.md) S12. 개발/배포 승인은 연구 실행·연락·녹화 승인으로 확대되지 않는다.

## 참여자 설명문 초안

화음 수리점은 화면의 음을 바꾸며 화음 관계를 살펴보는 웹앱입니다. 이번 관찰의 목적은 사용하기 어려운 부분과 설명이 혼동되는 부분을 찾는 것입니다. 여러분의 음악 실력이나 피아노 연주 능력의 우열을 평가하려는 자리가 아닙니다. 이 앱의 교육효과가 검증되었다고 안내하지 않습니다.

참여하면 앱을 직접 사용하고, 선택된 경우 앱과 다른 간단한 음 타일·소리 비교 질문에 답할 수 있습니다. 진행자는 어떤 동작이 어려웠는지 메모할 수 있습니다. 모르는 질문은 건너뛰어도 되고, 휴식하거나 언제든 참여를 끝낼 수 있습니다. 게임 이용은 연구 참여나 기록 동의에 묶이지 않습니다. 소리 없이 사용할 수 있으며 음량은 본인이 편안한 수준으로 조절할 수 있습니다.

기록의 목적·항목·보관 기간·접근 담당자·철회 방법은 위 운영자가 확정한 안내에 따릅니다. 기본 계획에서는 실명·생년월일·주소·진단명·연락처·음성·영상·화면 녹화를 관찰 기록으로 수집하지 않습니다. 관찰에 필요한 기기 정보와 수행·설명 메모에 관찰 코드를 사용합니다. 코드나 자유 메모에 개인을 알아볼 정보가 남을 수 있으므로 “완전 익명”이라고 약속하지 않습니다.

녹화나 후속 연락이 필요해지면 목적과 범위를 따로 설명하고 선택 동의를 받습니다. 선택 항목을 거부해도 앱을 사용할 수 있습니다. 지연 평가를 하지 않거나 연락을 원하지 않는 선택도 가능합니다. 현재 이 문서는 초안이며 실제 연락이나 예약을 시작하지 않았습니다.

## 선택 확인 양식 — 실제 사용할 때만 작성

- 관찰 코드: __________
- 사용 안내문 버전/날짜: __________
- 설명을 제공한 담당자: __________
- 참여자가 이해할 수 있는 방식으로 설명하고 질문 기회를 제공했는가: __________
- 관찰 참여 및 아래 확정 항목의 메모에 동의: 동의 / 미동의
- 소리 사용: 원함 / 무음 원함 / 중간에 선택 변경 가능
- 선택 사전·사후 문항: 참여 / 건너뜀
- 별도 녹화: 기본 미수집. 별도 승인·설명·동의서가 없으면 실행하지 않음
- 7–14일 후 평가 연락: 기본 미수집·미예약. 별도 설명·동의를 받은 경우에만 선택
- 중단/철회 방법을 안내받음: __________
- 담당자가 기록할 동의 확인 방식과 시간: __________

서명·실명·연락처가 필요한 실제 운영 방식은 담당자가 먼저 정하고 관찰 데이터와 분리한다. 현재 빈칸에 가상의 참여자나 동의 정보를 채우지 않는다.

## 최소 데이터 계획

| 항목 | 필요 목적 | 기록 원칙 |
|---|---|---|
| 관찰 코드 | 동일 세션/형식 연결 | 실명이나 이메일에서 파생하지 않음; 대응표가 필요하면 별도 제한 보관 |
| 사전 경험 큰 범주 | 입문자/숙련자 결과 구분 | 자기보고 선택형, 불필요한 상세 이력·학교·직장 수집 없음 |
| 기기/OS/브라우저·입력·출력·AT | 문제 재현과 조건 비교 | 하드웨어 고유 ID/계정명/시리얼 없음; 필요한 최소 버전만 |
| 과제 행동·첫 응답·도움·답 노출 | 조작 및 독립성 판단 | 전체 브라우징/키 입력 감시 없음; 해당 과제 사건만 |
| 짧은 설명 메모 | 혼동 이유 파악 | 연락처·개인 사연 제거; 인용 공개는 별도 범위 확인 |
| 점수·결측 사유 | 항목별 결과 구분 | 질문을 보지 않은 사람을 오답 처리하지 않음 |
| 참가자 선택 지원 | 접근성 조건 파악 | 진단명 요구 없음; 실제 사용 도구/지원만 기록 |
| 연락처 | 선택 지연 연락이 승인된 경우에만 | 관찰표와 분리, 목적·연락 횟수·삭제 시점 확정, 동의 없으면 수집 안 함 |

앱 기본 analytics나 서버 학습 기록 전송은 추가하지 않는다. 연구를 위해 사용자 전체 저장 파일을 자동 업로드하거나 실제 DB를 지우지 않는다. 내보낸 앱 기록이 꼭 필요하면 별도 설명·선택 범위·최소화 검토를 한다. 녹화·음성·민감정보는 기본 수집하지 않는다.

수집 전 보관 위치·접근자·기간·삭제 절차·철회 범위를 확정한다. 공개 저장소에는 실제 참여자 기록·연락처·동의 자료를 commit하지 않는다. 보고에는 필요한 집계와 식별정보를 뺀 사례만 사용하고, 소표본 조합으로 사람이 드러날 수 있는 세부정보를 점검한다. 현재 저장소의 연구 문서는 빈 계획·템플릿뿐이다.
