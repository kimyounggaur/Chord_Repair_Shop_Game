# S12 관찰 및 평가 기록 빈 양식

작성일: 2026-10-19 UTC. 상태: **템플릿만, 관찰 미실시(NOT RUN)**. 아래 빈칸은 실제 결과가 아니며 참여자·응답·점수·정확도·효과·인용을 채워 넣지 않았다. 실제 자료는 승인된 별도 보관 위치에서 관리하고 공개 저장소에 commit하지 않는다.

사용 기준: [usability-protocol.md](usability-protocol.md), [transfer-plan.md](transfer-plan.md), [consent-template.md](consent-template.md). S11 이후 연구 실행 여부가 확정된 경우에만 이 양식을 복제해 사용한다.

관찰 초점: 시작 소리/무음 선택, 목표·원래·현재 구별, 음 교체·scroll/pinch·오탭·undo, CR03 근음 변경, CR04 Bb/A# 문맥, CR05/06 첫 힌트, CR07/08 역할 확인, 질문 전 해설, 합주/자유 실험, 기기 내 저장 이해. 사건을 보지 못했으면 추측 대신 미관찰로 기록한다.

## 앱 내 결과 — 독립 전이와 별도

| 주문 ID | 첫 제출 / 유효 여부 | 최종 수리 | repair 도움 최대 | reflection 도움 최대 | 첫 질문 응답 | 첫 답 전 해설/시범/정답 노출 | 증거 known/unknown | 비고 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

최종 수리는 처음 오답을 지우지 않는다. 도움/질문 skip/무음은 수리 보상 차별 사유가 아니다. 새로고침·reset·undo 후 도움/노출 증거가 사라지면 제품 결함으로 따로 기록한다. 화면에서 읽은 값과 실제 저장 파일을 확인한 범위를 구분한다.

## 독립 평가 문항별 기록

| 시점·형식·문항 ID | 실제 제시 조건/순서 | 첫 응답 | 수정 응답 | 기준별 정답/오답 | 도움·relatedItem 노출 | independentEligible 및 이유 | 결측/제외 사유 | 채점자/검토 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

상태 구분:

- 유효 첫 응답: 표준 조건에서 답함. 정답/오답을 기록할 수 있음.
- 연습/도움 응답: 정답 여부와 별도로 독립 분석 제외 이유를 기록.
- NOT ADMINISTERED: 배정하지 않거나 아직 제시하지 않음.
- SKIPPED/STOPPED: 참여자 선택으로 건너뛰거나 종료. 0점으로 환산하지 않음.
- TECHNICAL FAILURE: 소리/입력/화면 등으로 의도한 조건을 제시하지 못함.
- UNKNOWN: 이전 노출·첫 답변·개입 증거가 불충분. 독립으로 추정하지 않음.

새 배치 인식·다른 악기 과제는 탐색적 결과로 별도 보고한다. 음 선택과 운지·도구 조작·독보는 서로 다른 관찰값이다. 무음은 HEAR 미실시이며 구조 문항 성취를 무효화하지 않는다.
