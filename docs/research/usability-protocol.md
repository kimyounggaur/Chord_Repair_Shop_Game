# S12 사용성 관찰 준비 계획

작성일: 2026-10-19 UTC. 상태: **준비만 완료, 관찰 미실시(NOT RUN)**. 대상 연령·기초 수준·실제 기기·담당자·모집 방식은 미확정이다. 참가자 모집·연락·일정 예약·녹화·데이터 수집을 하지 않았다. 이 문서의 준비는 S12 관찰 또는 전체 단계 PASS를 뜻하지 않는다. S11 기술 검증 이후 실행 준비와 남은 게이트를 판정한다.

기준: [설계서](../design.md) 2장, 5–6장, 12장, 20.8장, 22–23장 및 [프롬프트팩](../promptpack.md) S12. 설계의 6–8명은 조작 장애를 찾기 위한 소규모 제안이며 교육효과를 입증하는 표본 수가 아니다.

## 목적과 결과의 분리

1. 사용성: 처음 본 사람이 목표/원래/현재를 구분하고 음 교체·되돌리기·듣기·질문·설정·저장 경로를 찾는지 관찰한다.
2. 개념 확인: 근음·3음·5음과 장·단의 간격을 어느 근거로 판단했는지 확인한다. 앱 내 질문의 첫 답변과 노출/도움 이력을 함께 읽는다.
3. 전이: 별도 도구·새 근음·배치에서 관계를 적용하는지 탐색한다. 독립 평가 문항이 앱에서 연습되거나 답을 먼저 보았다면 독립 결과에서 제외한다.

8주문 완료율, 개념 답변, 전이를 합친 음악 실력 점수는 만들지 않는다. 엔진이 음을 재생한 사실은 참가자의 장·단 청각 식별 성취가 아니다. 무음 경로는 구조 학습으로 기록하며 청각 평가를 0점 처리하지 않는다. 피아노 운지·독보·지능·집중력·일반 학업 향상은 평가 목표가 아니다.

## 실행 전에 확정할 조건

| 조건 | 현재 상태 | 진행 담당자가 확정할 내용 |
|---|---|---|
| 기술 후보 | S11 이후 판단 | releaseId/commit/contentVersion, 알려진 결함, 실제 가능한 입력·오디오·저장 |
| 대상 | 미확정 | 연령 집단, 음악 입문자 기준, 기존 경험의 큰 범주, 포함/제외 이유 |
| 인원 | 6–8명 제안만 있음 | 관찰 목적과 자원에 맞는 실제 인원. 숙련자와 입문자 결과를 합치지 않음 |
| 권한 | 연구 실행 승인 없음 | 모집·연락·연구 진행·선택 녹화·지연 연락을 각각 필요한 범위로 승인 |
| 동의 | 초안만 있음 | 담당자/문의 경로, 보관 위치·기간·삭제일·철회 절차, 미성년자 절차 해당 여부 |
| 기기 | 미확정 | 모델/OS/브라우저/입력 수단/출력/AT, 개인 기기 사용과 테스트 기록 분리 |
| 평가 | 제안 문항만 있음 | A/B 배정, 이전 노출 확인, 음표·타일·반음표 지원 수준, 채점자 검산 |

미성년자가 대상이 되면 담당자가 필요한 보호자 및 참여자 설명 절차를 먼저 확정한다. 대상이 정해지기 전 아동용 연구라고 단정하지 않는다. 현재 개발·GitHub·Vercel 배포 승인은 연구 참여자 모집/연락/녹화 승인으로 확장하지 않는다.

## 진행 순서 제안

시간은 진행자의 일정 초안이며 참가자에게 속도 목표나 경쟁 조건을 주지 않는다. 휴식·건너뛰기·종료가 언제든 가능하다. 사전/사후 평가를 포함하면 설계의 8주문 체험 15–25분보다 길어질 수 있으므로 총 소요시간은 파일럿 후 안내문에 확정한다.

| 순서 | 진행자 행동 | 관찰/기록 | 제한 |
|---|---|---|---|
| 0 준비 | 동의 및 기기 확인, 익명 대신 가명 관찰 코드 부여 | 동의 범위, build와 기기, 필요한 지원 | 실명·생년월일·진단명·연락처를 관찰표에 적지 않음 |
| 1 사전 선택 평가 | 독립 전이 계획이 승인되었을 때만 배정 문항 시행 | 첫 응답·노출·도구 조건 | 정답 피드백/힌트 없음. 사용성 관찰만이면 생략 가능 |
| 2 시작 | “화면을 보며 시작해 주세요. 막히면 말씀해 주세요.” | 소리 켜기/무음 선택과 이유, 시작 버튼 탐색 | 사전에 정답·수리할 슬롯을 설명하지 않음 |
| 3 CR01/02 | 조작을 지켜보고 필요 시 중립 질문 | 목표/원래/현재 구별, 음 선택, undo/reset, 질문/해설 순서 | 가운데/E를 누르라는 유도 금지 |
| 4 CR03/04 | 다른 근음 및 검은건반 문맥 관찰 | 관계 사용 여부, Bb/A# 문구 이해, 스크롤·오탭 | C/F/G 정답을 암기했는지 질문으로 단정하지 않음 |
| 5 CR05/06 | 자동 힌트 없는 첫 접근 관찰 | 첫 제출·자발적 도움·거리 도구 사용, 피드백 해석 | 침묵/지연만으로 힌트를 자동 제공하지 않음 |
| 6 CR07/08 | 첫 선택과 그 근거 관찰 | 항상 가운데만 바꾸는지, 5음/근음 관계를 살피는지 | “5음/근음을 고치세요”라는 정답 암시 금지 |
| 7 완료/자유 실험 | 합주·부분 듣기·자유 실험 안내를 찾게 함 | 보상의 의미, 자유 실험이 평가인지 이해 | 강제 청취/청각 과제로 완료를 막지 않음 |
| 8 저장/설정 | 진행·설정·내보내기 안내를 찾게 함 | 기기 내 저장 이해, 큰 버튼·무음·모션 선택 | 참여자 실제 저장을 손상시키거나 초기화하지 않음 |
| 9 사후 선택 평가 | 승인된 미노출 평행 문항 시행 | 새 형식의 첫 응답과 노출 조건 | 앱 질문 반복을 독립 전이로 세지 않음 |
| 10 마무리 | 경험 질문, 평가 종료 후 해설, 철회 안내 | 관찰과 참가자 해석을 분리 | 지연 연락 동의 없이 연락/예약하지 않음 |

## 중립 질문과 개입 기록

허용 질문 예:

- “지금 어떤 주문을 맞추고 있다고 생각하나요?”
- “원래 소리와 현재 소리는 각각 어느 버튼이라고 생각하나요?”
- “무엇을 보고 그 음을 골랐나요?”
- “근음이 바뀌면 무엇을 확인하나요?”
- “이 안내를 어떻게 이해했나요?”
- “지금 무엇을 하고 싶은데 찾기 어렵나요?”

피할 질문: “가운데를 바꿔 보세요”, “여기는 5음이 문제죠?”, “단화음은 슬프게 들리죠?”, “힌트 없이 잘 이해했죠?”. 진행자는 관찰 행동을 먼저 적고 해석은 별도 칸에 적는다.

도움을 요청받으면 먼저 중립적 탐색 질문을 할 수 있다. 실제 조작을 대신하거나 관계·정답을 알려주면 개입 시점/내용/노출 문항을 기록한다. 지원 장치 설치, 텍스트 읽기·확대, 큰 버튼 전환 같은 접근성 지원 자체는 이론 힌트가 아니다. 지원 과정에서 답을 알려주었을 때만 해당 답 노출로 기록한다. 개입한 뒤 결과를 도움 없는 수행으로 보고하지 않는다.

## 관찰 분류

| 관찰 | 구분할 가능성 | 성급히 내리지 않을 결론 |
|---|---|---|
| 검은건반을 잘못 탭 | 터치 타깃/스크롤/손가락 오탭 | 음악 개념 오답이라고 단정 |
| CR07에서 3음만 반복 변경 | 가운데 위치 전략 또는 안내 혼동 | 참가자의 능력 부족으로 낙인 |
| C는 맞지만 F/G에서 멈춤 | 고정 음 이름 암기, 새 근음 부담, UI 위치 변경 | 게임 학습효과 없음/있음 단정 |
| 단화음에 검은건반이 필요하다고 설명 | 오개념 후보 | 실제 A단 반례 응답 없이 확정 |
| 음이 안 들린다고 말함 | autoplay/mute/OS volume/출력/기기 | AudioContext running만으로 참가자 오류 처리 |
| 관계 질문 전에 이유를 이미 봄 | 도움/시범/튜토리얼/해설 노출 | 독립 개념 성취로 집계 |
| 새로고침 후 기록 혼동 | 저장 결함·설명 부족·기기별 저장 기대 | 연구 기록을 위해 실제 데이터를 파괴 |

문제의 영향은 진행 차단/학습 증거 오염/기능 오류/혼동/장식으로 나눠 기록한다. 음악 오류·갑작스러운 소리·기록 삭제·독립 증거 오염은 기술팀에 즉시 전달한다. 불편·피로·원치 않는 음량·중단 요청이 있으면 해당 과제 또는 관찰을 멈춘다. 종료는 실패로 채점하지 않는다.

## 결과 보고와 후속

- 현재 관찰 결과와 효과 수치는 없다. 빈 템플릿을 결과 보고서로 읽지 않는다.
- 조작 도움 없이 음 교체/목표·원래·현재 구별의 80%는 설계의 내부 수정 판단 목표다. 달성한 수치가 아니며 소표본 일반화 기준도 아니다. 실제 시행 후 성공 수/평가 가능 수/제외 이유와 개별 사례를 함께 보고한다.
- 수리 완료, 앱 개념 첫 답변, 외부 전이 각 항목을 별도로 보고한다. 도움·정답 노출·무음·선행경험·천장 효과와 결측을 함께 제시한다.
- 관찰 결함은 용어·입력·비교 조건·안내 제거 시점을 먼저 고치고 S07/S09/S11 회귀를 수행한다. 재관찰은 가능하면 같은 부류의 새 참여자로 하며 이전 참여자의 반복 효과를 구분한다.
- S13 인계: 준비 문서 있음, 관찰 미실시, 교육효과 미검증, 대상/동의/기기/담당자 미확정. 이 상태를 정식 출시 관찰 게이트 통과로 표시하지 않는다.
