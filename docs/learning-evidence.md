# Learning records

Repairs, first submissions, final success, maximum repair/reflection help, first/latest concept answers, skips and pre-answer exposure remain distinct. Guided CR01/02 cannot qualify as independent checks. Muting, keyboard, large pads, reduced motion and notation preferences never count as help. Assistance and wrong/skipped questions earn the same instrument and ensemble access.

Original questions and answer indices are unchanged. The reducer stores stable option IDs and their seeded permutation. UI renders that order directly. `tests/integration/learning.test.ts` covers all eight orders and 100 seeds per order; browser `eight-orders.spec.ts` exercises the real first-course flow. These establish implementation behavior, not educational effectiveness.
