check 안에서 실행된 하위 명령을 각각 별도 실행했다고 기록하지 않는다. reference의 59 events와 시간 수치는 독립 참고 산술이며 아직 앱의 합주 builder/오디오 재생 검증은 아니다. 이후 단계의 테스트 증가와 결과는 해당 인계 파일에서 기록한다.

최초 `npm run check`의 저장된 로그 경로는 **없음(콘솔 전용)**이다. 주 실행 에이전트가 로그 저장을 위한 재실행을 예정하고 있으나, 예정은 실행 증거가 아니다. 브라우저 스크린샷·trace도 이 기록 시점에는 없다.

## S01 입력과 먼저 할 일

Node/패키지 버전은 `../toolchain.md`, 원본 계약은 `../design.md` 및 `../promptpack.md`, 주문은 `../../src/content/orders.v1.json`을 읽는다. S01은 `domain/music`의 순수 음악 함수와 테스트부터 작성한다.

음악 API 초안은 설계 13.3을 따른다: `SpelledPitch`, `Quality`, `Role`, `ChordTarget`, `Grade`; 음 표기 파싱/검증, spelled pitch ↔ MIDI, pitch class, 정확한 문자 기준 음정, 근음 문자 +2/+4를 따르는 장/단3화음 생성, 음역/전위 판정의 기초를 분리한다. 구현 전 S01의 수용 테스트를 원문에서 읽고 함수 이름과 실제 signature를 확정한다.

유지할 불변식: C4=60, major [0,4,7], minor [0,3,7], 음고/철자/음역/전위 분리, exact는 MIDI 다중집합, D#와 Eb의 입력 문맥 정규화, 표시 문구를 정답 입력으로 사용하지 않기. 음악 도메인은 DOM/React/AudioContext/IndexedDB/저장 UI를 import하지 않는다.

## 후속 증거 추가란

후속 실행 담당은 이 아래에 실제 명령·exit code·로그 또는 화면 경로를 추가한다. 최초 콘솔 전용 기록과 미실행 상태의 이력을 삭제하지 않는다.

### 2026-10-19 — 저장 로그와 실제 Chromium 셸 확인 추가

- 주 실행 에이전트가 `npm run check`를 로그 저장 목적으로 다시 실행하고 exit 0을 보고했다. `../evidence/S00-check.log`(1,434바이트)를 문서 담당이 직접 읽어 reference PASS, 타입 검사, unit smoke 1 passed, Vite production build 성공을 확인했다. 로그의 Vitest 시작 시각은 `22:10:15`, 테스트 기간은 553ms이며 Vite 빌드는 215ms로 출력된다. 시간대 정보는 로그에 없으므로 추가하지 않는다.
- Chromium 156.0.8078.4 (Playwright browser build v1248)에서 `tests/e2e/shell.spec.ts`가 **1 passed / 3.0s**로 성공했다는 실행 결과를 받았다. 테스트 파일을 직접 읽어 페이지 제목, `html lang=ko`, 화음 수리점 heading 표시 검사임을 확인했다. 게임 조작·소리·휴대기기 테스트가 아니다.
- 제한 실행 환경에서 서버/Playwright가 소켓 오류를 겪었으며, 주 실행 에이전트가 `require_escalated` 환경에서 서버와 Playwright를 실행해 성공했다고 보고했다. 최초 오류의 전체 명령·원문·exit code는 이 문서에 전달되지 않았으므로 추정하지 않는다. 당시 콘솔 기록이 실패 증거다. 이 상황을 자동 승인 거절로 기록하지 않는다.
- 개발 서버는 지정 포트 5486에 유지되었다는 보고를 받았다(작업 도구 session 72334). 이 session ID는 일시적 실행 상태이며 재현 명령이나 배포 URL이 아니다.
- Playwright 설정은 `trace: retain-on-failure`, `screenshot: only-on-failure`이다. 통과 후 화면 스크린샷/trace는 확보한 것으로 기록하지 않는다. `test-results/.last-run.json`은 실행 상태 보조 자료이며 ignored 산출물이다.

위 추가 근거로 초기의 “브라우저 셸 NOT RUN” 항목은 **최소 Chromium 셸 검사 PASS로 해결**되었다. 최초 콘솔 전용 check도 저장된 재실행 로그로 보강되었다. 실제 청취·실기기·전체 게임 E2E와 다른 후속 검사의 미실행 상태는 그대로다.
