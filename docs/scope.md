# 구현 범위

기준: `design.md` v1.0 및 `promptpack.md` v1.0. 프로젝트 이름과 namespace는 **화음 수리점 / chord-repair-shop**이다. 이 저장소는 현재 PC의 별도 작업 폴더이며 다른 게임의 코드·진행·저장 공간을 합치지 않는다.

## MVP

- C, Cm, F, Fm, G, Gm과 정확히 CR01–CR08의 원본 주문을 제공한다.
- MIDI 60–74, 지정 음역의 기본 위치 세 음을 탭/큰 음 버튼/키보드로 조작한다. exact 판정은 MIDI 다중집합을 비교하며 슬롯 순서나 Set만으로 판단하지 않는다.
- 근음·3음·5음, 반음, 장3도·단3도·완전5도의 관계를 탐색한다. 음고·철자·음역·전위를 구별한다.
- 무음 완료 경로, 되돌리기/원래 상태 복원, 3단계 도움, 관계 질문, 도움·답 노출 이력과 독립 해결 증거를 분리한다.
- 사용자 제스처로 시작하는 단일 Web Audio 엔진, 동일 조건의 전후 비교, 중단/복귀 시 명시적 재생, 취소와 voice 정리를 구현한다.
- 기기 내 IndexedDB 진행·설정, 내보내기/가져오기, 손상 복구와 두 탭 충돌 처리를 구현한다.
- 모바일 세로 화면을 기본으로 확대·가로 화면·키보드·스크린리더에 동등한 조작 경로를 제공한다.
- 자유 실험, 8마디 교대 합주와 독립적인 수리점 그림을 연결한다. 합주 기준은 59 NoteEvent, 본문 24초, transport 종료 24.4초다.
- 한 번 불러온 세션은 네트워크가 끊겨도 핵심 수리를 계속할 수 있게 한다.

## 후속 범위

전위 강좌, 다른 근음 강좌, 감/증3화음, 7화음, MIDI 입력, 마이크/연주 인식, 계정, 결제, 광고, 원격 학습 데이터, LLM 런타임, 서버, PWA 재실행 오프라인, 푸시, 랭킹, 생명, 타이머 경쟁은 MVP에 넣지 않는다. 후속 기능의 빈 잠금 메뉴도 만들지 않는다. 일반 함수의 전위·이명동음 테스트는 안전장치이며 해당 강좌가 출시되었다는 뜻이 아니다.

## 실행 순서와 승인 범위

M00의 공통 계약을 적용하고 S00–S14를 순서대로 구현·검증한다. 현재 사용자는 지정 GitHub 저장소의 commit/push와 별도 Vercel 프로젝트의 배포까지 승인했다. force push, 원본 백업 변경, 새로운 자격증명 생성, 권한 확장, 유료 결제는 승인 범위에 포함되지 않는다. 기존 인증을 사용하며 사용량 제한이 나오면 우회하거나 모델을 바꾸지 않는다.

S00은 원본 보존, fixture 추출, 도구 고정, 최소 앱 셸과 자동 검사 기반을 만든다. 오디오·DB·아트 통합·배포 완료를 S00의 결과로 주장하지 않는다. 실제 단계 상태와 증거는 `implementation-status.md` 및 `handoffs/`가 관리한다.

GitHub 대상: `https://github.com/kimyounggaur/Chord_Repair_Shop_Game`. Vercel은 다른 게임과 분리된 프로젝트를 사용하며 READY, 커밋 연결과 운영 URL 접근을 확인한 뒤 결과를 기록한다.

## 검증과 표현의 경계

단위/통합 검사, 브라우저 자동화, 실제 청취, 실제 휴대기기 조작, 보조기기 시험과 참가자 학습 연구는 서로 다른 증거다. 가능한 자동 검사는 실행하되 확보하지 않은 기기·사람의 결과를 PASS로 대신하지 않는다. 학습 효과, 피아노 운지·자세·악보 독해 성취 또는 무음 사용자의 청각 구별 성취를 주장하지 않는다. 참가자 모집·연락·동의가 필요한 연구는 준비물과 실제 수행을 구분한다.
